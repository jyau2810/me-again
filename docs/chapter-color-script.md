# 《我》五章色彩脚本

版本：v0.1
日期：2026-08-14
状态：Stage 4 规划基线

本文为 30 幕的构图灰稿、分层资产和状态图提供可复查的颜色边界。颜色服务现实光源、材质和感知变化，不按章节给整张画面套统一滤镜；每幕必须同时保留中性结构色、环境色和一个有限的叙事强调色。

## 1. 全局颜色规则

- sRGB；背景、人物和物件在同一场景使用同一光向与白平衡基准。
- 现实段以中性灰、自然木色和实际光源为主；入界通过局部反射、材质温度与明度关系发生，不做全屏蓝/黄渐变。
- 暖色不是“正确答案”，冷色也不是“失败”。成功/失败先由物件动作、节奏和空间变化表达。
- 人物肤色基准为暖中性：亮部参考 `#DFB08A`、中间色 `#C58F69`、阴影 `#865B49`；只作校色参考，不把三色硬画成赛璐珞分区。
- 成年基础服装以炭蓝 `#303B45`、石墨 `#2C2F31` 为主；五岁服装可使用稍浅的雨蓝 `#596C7E`、灰绿 `#68766A`，但不得靠鲜艳颜色制造幼态。
- 交互物在实际显示尺寸下靠轮廓、材质差和局部运动可读；禁止用高饱和描边、通用按钮光圈或大面积互补色强行突出。
- 同一状态组必须在授权区域内改色。背景、人物或物件未授权区域的像素、Alpha 和光向不得漂移。

## 8. 使用与验收

1. 构图灰稿先用明度块验证空间，颜色不得掩盖比例、承载和交互问题。
2. 单项资产提交时附本幕色彩行和实际光源说明；透明物件同时在浅、深两种底色检查。
3. 合成预览至少输出初始态与完成态，并用像素差或遮罩确认变化只发生在授权区域。
4. 若生成结果整体偏向单一蓝、黄、棕或灰，应先恢复材质本色，再调整局部强调色，不能继续叠滤镜补救。
5. 若用户确认的新资产改变章节色温或叙事强调色，应同步更新本文、对应单幕清单和 `docs/development-plan.md`。
