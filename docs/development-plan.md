## 阶段 3：单幕精细化样板

状态：进行中

重新启动日期：2026-08-07

### 本轮目标

先只制作 `c01_s02_commute_window`，用一幕验证新的生产顺序：

1. 从母本与第一章制作脚本提取场景情绪、构图、人物和交互物件。
2. 生成三种原创视觉方向稿，确认后锁定全项目视觉语言。
3. 在已选方向下确认构图灰稿，再分别生产无人物场景背景、成年主角、小孩倒影、手机、车灯、车牌和必要状态图。
4. 每项资产独立确认，不把人物或可交互物件永久画进背景。
5. 合成场景后，通过 Godot 校正工具人工调整位置、缩放、层级、可见范围和命中热区。
6. 最后接入三次车窗观察、主角抬头、倒影变化和车灯反馈，再进行单幕验收。
